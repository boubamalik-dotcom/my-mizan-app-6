# El Mizan Real Estate — Mobile App

تطبيق Flutter لوسيط عقاري ذكي لمدينة **وهران** يعمل بمنطق الميزان.

## الهيكل

```
lib/
├── main.dart
├── views/          # الشاشات
├── controllers/    # منطق التحكم
├── models/         # نماذج البيانات
└── services/       # خدمات API
```

## التشغيل

```bash
flutter pub get
flutter run
```

تأكد من تشغيل خادم الـ backend على المنفذ `8000`.
