## 📱 الميزات الرئيسية

### ✨ للطلاب
- 📸 **ماسح الإجابات**: صوّر إجابتك والتطبيق يقيّمها فوراً
- 🧠 **تحليل ذكي 5-طبقات**:
  - طبقة لغوية (دقة المصطلحات)
  - طبقة منطقية (صحة الاستدلال)
  - طبقة تنظيمية (مطابقة الباريم)
  - طبقة تقييم (محاكاة المصحح)
  - طبقة تنفيذية (خطة التحسين)
- 📊 **نتائج مفصلة**: رؤية سبب خسارة النقاط
- 🎯 **توقع البكالوريا**: تنبؤ دقيق بدرجتك الحقيقية
- 💪 **مؤشر الطاقة**: تنبيهات عندما تشعر بالتعب
- 👥 **لوحة المتصدرين**: تحدٍ مع الطلاب الآخرين
- 🤖 **معلم ذكي 24/7**: إجابة فورية على أسئلتك

### 👨‍🏫 للمعلمين
- 📊 **لوحة معلومات الفصل**: تابع أداء كل الطلاب
- 📈 **تحليل الأداء**: فهم نقاط الضعف الشاملة
- 📋 **إدارة الواجبات**: أنشئ اختبارات وواجبات
- 📑 **تقارير مفصلة**: تصدير نتائج الطلاب

### 👨‍👩‍👧 للآباء
- 👶 **متابعة الأطفال**: شاهد تطور أطفالك
- ⚠️ **تنبيهات ذكية**: اعرف عندما يحتاج الطفل مساعدة
- 📞 **التواصل مع المعلم**: ابقَ على اتصال مباشر

## 🚀 البدء السريع

### المتطلبات
- **Node.js** 14+ ([تحميل](https://nodejs.org/))
- **Git** ([تحميل](https://git-scm.com/))
- **npm** أو **yarn**

### التثبيت المحلي

```bash
# 1. استنساخ المشروع
git clone https://github.com/YOUR_USERNAME/mizan-app.git
cd mizan-app

# 2. تثبيت المتطلبات
npm install

# 3. تشغيل المشروع
npm start

# سيفتح تلقائياً على: http://localhost:3000
```

### البناء للإنتاج

```bash
# بناء نسخة الإنتاج
npm run build

# اختبار النسخة المبنية
npm start
```

## 🌐 النشر على Vercel

### الطريقة الأسهل (موصى به):

```bash
# 1. تثبيت Vercel CLI
npm i -g vercel

# 2. تسجيل الدخول
vercel login

# 3. النشر
vercel --prod
```

**سيحصل على رابط حي مثل:** `https://mizan-app.vercel.app`

## 📞 الدعم والمساعدة

### المشاكل الشائعة

**المشكلة: "Module not found"**
```bash
الحل:
npm install
npm install lucide-react
npm start
```

**المشكلة: Port 3000 مشغول**
```bash
الحل:
# على Windows
netstat -ano | findstr :3000
taskkill /PID <PID> /F

# على Mac/Linux
lsof -ti:3000 | xargs kill -9
```

**المشكلة: Build Failed**
```bash
الحل:
rm -rf node_modules package-lock.json
npm install
npm run build
```
